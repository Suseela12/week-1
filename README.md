# Gemini Prompt Engineering Lab

## Aim

To configure a Python environment and communicate with Google's Gemini language model using an API key.

## Requirements

* Python 3.8+
* Google Colab
* Gemini API key
* `google-genai` Python library
* Internet connection

## Input

`What is prompt engineering? Answer in one sentence.`

## Procedure

1. Install the Google GenAI SDK.
2. Configure the Gemini API key securely.
3. Define the input prompt.
4. Send the prompt to the Gemini model.
5. Display the generated response.
6. Save the input and output to text files.

## Expected Output

A one-sentence explanation of prompt engineering generated by Gemini.

## Result

Successfully demonstrate the workflow for sending a prompt to Gemini and receiving a generated response.

## Security

Never commit API keys, passwords, or `.env` files to GitHub.
